# PassKeeper

A secure, offline-first password manager (Flutter).

## Run

```bash
flutter pub get
flutter run
```

## Structure

See `lib/` — feature-based modules: `welcome`, `onboarding`, `unlock`, `vault`, `generator`, `settings`.

## Status

Scaffold + UI for the four design screens (Welcome, Vault, Generator, Settings) plus onboarding/unlock. Crypto, persistence, and hardening are tracked in `TASKS.md`.
